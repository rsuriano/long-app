# Screenshots

This folder is a visual record of each phase. The screenshots are 390×844 (iPhone). We
took them with Chrome on the dev server. Use them to see the changes without a local
start of the project. They are also a design reference.

- `fase-1/` — the real prompt with AI. It contains the prompt screen, the loading screen
  while the app waits for the model, and the basket that the model returned. It also
  contains a case with exclusions ("AI without Zuckerberg" → no Meta). The model writes
  the names, the notes, and the order. The formula calculates the weights.
  - `5-gate` and `6-gate-error`: the access gate of the private preview.
  - `7-drift` and `8-drift.gif`: the logos of the icon, which drift in zero gravity.
